# v2交付验收

## 分层证据
1. 分镜：35幕原文逐项对应；每幕画面目的明确；默认22真实／13Remotion／0AI，真实至少20幕。两类比例调整有口播依据；动态内嵌真实图不重复计数，重复截图不用于凑额。检查真实主线完整、动态承担解释；不得存在AI生图幕或生图依赖。
2. 源素材：查看实际PNG；复用用户已观看认可的原片及其验收证据，不重复要求采集端连续观看；没有窗口抖动、闪白、意外滚动、无信息裁切；应用原生控件不伪造。记录人/Agent实际检查范围。
3. 组装：accepted资产才能绑定；日期、单位、周期、指标口径与口播一致；QA后文件变化要重验；音频文字一致；源片足够覆盖音轨。
4. 手机画幅：按约360px宽查看完整构图，再看原尺寸必要文字；不以1080p分辨率代替可读性。电脑与手机分别使用固定外框、16px内边距与统一背景；同类截图/录屏位置相同，原图或crop等比完整容纳。细节通过有意义的区域放大，关键标题、数值、单位、图例不得裁丢；相邻操作不无故跳变尺度。至少检查每种实际使用的版式、长字幕及细节裁切实例。
5. 动态预览：真实界面不套推入、弹跳或无意义变焦，外框/品牌/字幕固定。视频使用幕内时间与源片起点，核对实际编码的动作、首末帧，防止全片时钟导致后段录屏冻结。静帧不能证明无抖动；已有用户实看认可记录可作为源片证据，不因Agent播放能力限制卡住采集交付。
   Remotion内容动效逐幕看动作推进与口播对应：关系准确、运动有意义、节奏清楚、精致高级，关键落点有阅读时间。手机检查标签、真实证据、标注框和字幕无重叠遮挡，图表上下文完整。单纯列表或依次点亮卡片不能自动达标；按 `motion-effects.md` 分品牌核对默认风格：财叔对照认可v06的配色、字体、材质与节奏（`motion-style-caishu-editorial.md`），秒懂保持白底手绘线稿（用户另有指定除外），同时检查图形与动作是否贴合本幕口播；不要求固定布局或复刻历史效果，不以整套效果换字套用作为后续视频的默认制作方式。新ID须有实际组件、动态预览与候选源码快照，不能仅凭结构校验通过交付。
6. 编码后：核对1080×1920 H.264、人声音轨、必备BGM、总时长和边界帧；确认音乐覆盖全片、开尾淡入淡出、人声清楚且无削波，BGM来源/hash与组装配置一致；观看实际候选片，检查声音、字幕和画面对应。像素对照只证明渲染未新增变化，不证明源片正确。

真实界面重点展示另核对：观众能认出任务/对象与交付结果，重点数值和模型/单位处于同一真实上下文；没有仅把单行数字或按钮裁成窄条放大。标注框对准原始目标、留边不压字、不遮挡限定词，源文件保持原样。手机画幅中整体可辨认、重点可定位；必要细节不以丢失上下文为代价。
