## 一、Magpie 是啥？

Magpie 是 GitHub 上 yetone 大神做的一个开源项目。

这个大神是真的猛。他之前做的项目火了以后，OpenAI 和 xAI 都曾经直接在 Twitter 上公开给他发 offer、邀请他去工作。

**你把 Magpie 理解成一个“模型总控台”就行。**

它的逻辑其实特别简单。

原来你在一个 Agent 里登录了一份订阅，这份订阅里的模型，通常就跟着这个 Agent 走。

比如你登录了 Codex，你能用的是 Codex 这套账号背后的模型；你登录了 WorkBuddy，WorkBuddy 里面又有自己的一批模型。哪怕这些模型你都已经有权限用，它们平时还是分散在不同地方。

Magpie 在中间加了一层“总控台”。

**左边接你的模型和订阅，右边接你真正想用的 Agent。**

它先把 Codex、WorkBuddy、Qoder、Grok、Antigravity 这些账号背后的可用模型统一认出来，再通过本地的 Magpie 服务，把这些模型提供给其他 Agent。

所以你在 DeepSeek Harness 里选一个 WorkBuddy 的 DeepSeek，DeepSeek Harness 只管正常发任务。请求先到 Magpie，Magpie 再把它交给对应的 WorkBuddy 账号和 DeepSeek 模型，结果回来以后再原路送回 DeepSeek Harness。

对你来说，整个过程几乎是无感的。

**以前一份订阅只能老老实实待在自己的 Agent 里，现在 Magpie 可以把这份订阅背后的模型，拿去给别的 Agent 用。**

这就是它最核心的一件事。

## 三、怎么安装使用？

Magpie 本身已经做得非常简单了。

我的建议还是我最常用的方法。

**别自己一条一条敲，让 Agent 帮你装。**

如果你已经有 WorkBuddy，或者已经装了 DeepSeek Harness，直接把下面这段提示词贴过去。

> **直接复制下面这段提示词**
>
> 我想在这台电脑上安装并配置 Magpie，最终目标是把我自己账号里的 WorkBuddy、WorkBuddy AI、Qoder、Codex、Grok Build、Antigravity 等模型来源统一接入 Magpie，并让 DeepSeek Harness 桌面端可以直接选择这些来源里的模型。
>
> 请你直接在本机执行，不要只给我教程。
>
> 1. 先检查这台电脑的操作系统，以及 Magpie、WorkBuddy、Qoder、DeepSeek Harness 当前是否已经安装。已经存在的环境不要重复破坏。
> 2. 修改任何现有配置前先做备份，保留我现在能正常使用的模型和 Agent 配置。
> 3. 查阅 Magpie 当前最新的官方安装说明，使用官方推荐方式安装或升级 Magpie。
> 4. 安装完成后启动 Magpie，并确认本地服务可以正常工作。
> 5. 检查 Magpie 当前的插件和订阅接入方式，把 WorkBuddy / WorkBuddy AI / Qoder / Codex / Grok Build / Antigravity 等当前可接入来源统一接入。
> 6. 登录时优先复用我本机已有的账号登录状态。如果必须打开浏览器重新授权，请直接打开登录页面，然后停下来让我本人完成登录。不要向我索取密码、Cookie 或其他敏感凭据。
> 7. 登录完成后检查模型列表，确认这些来源里的当前可用模型已经被正确识别。
> 8. 把这些模型接入 DeepSeek Harness 桌面端。请确认修改的是桌面端真实使用的 desktop profile，不要只改 web profile。
> 9. 配置完成后重启或新建 DeepSeek Harness 会话，检查模型选择器里是否已经出现这些模型。
> 10. 最后用一个真实任务验收，确认模型可以正常调用工具。
> 11. 完成后告诉我最终接入了哪些模型、哪些账号来源可以使用、DeepSeek Harness 当前默认模型是什么，以及有没有还需要我手动处理的地方。

中间如果弹出浏览器，让你登录 WorkBuddy、Qoder 或其他账号，自己授权一下就行。

剩下的让 Agent 干。

有一个地方要特别注意。

**DeepSeek Harness 有 web 和 desktop 两套 Profile。**

我之前真正跑通桌面端时，改的是 desktop profile。如果 Agent 只改到了 web，你重启桌面版以后，模型列表很可能还是没变化。

这个一定要让 Agent 改对。
