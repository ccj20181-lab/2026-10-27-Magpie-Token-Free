## 一、Magpie 是啥？

Magpie 是 GitHub 上 yetone 大神做的一个开源项目。我觉得普通人完全没必要研究它背后什么协议转换、网关、接口兼容。

**你把它理解成一个“模型总控台”就行。**

你电脑里装了 Claude Code、Codex、DeepSeek Harness、OpenCode、Pi 这些 Agent，Magpie 会把它们统一列出来。你手里有 DeepSeek、Kimi、GLM、Qwen，或者各种大厂订阅、免费模型，也统一放进来。

接下来就干一件事，**点开一个 Agent，给它选一个你想用的模型。**

<!-- 配图02：Magpie Agents 主界面，展示多个 Agent 及其当前模型；账号、邮箱等隐私信息打码 -->

比如 Claude Code 想用 Kimi，可以；Codex 想用 DeepSeek，可以；DeepSeek Harness 想用 WorkBuddy 里的 DeepSeek，也可以。

而且整个过程做得非常“人类”。

至少在我现在这套多 Agent、多模型的用法里，我的使用体验是，**完爆之前的 CC Switch 等项目。**

CC Switch 我之前也折腾过，能解决问题，但多少还有点工程味。Magpie 用起来极其丝滑、简单，很多东西点几下就完事了。

更夸张的是，这个作者真的太勤奋了。

## 三、怎么安装使用？

Magpie 本身已经做得很简单了。

但普通用户看到安装、插件、模型、配置这些词，还是容易头大。

我的建议依然是我最常用的办法。**别自己一条条敲，让 Agent 自己给你装。**

如果你电脑里已经有 WorkBuddy，或者已经装了 DeepSeek Harness，直接把下面这段提示词丢给它。

后面的安装、检查、插件配置、模型接入，都让它自己干。

> **直接复制下面这段提示词**
>
> 我想在这台电脑上安装并配置 Magpie，最终目标是把我自己账号里的 WorkBuddy、WorkBuddy AI、Qoder 等模型来源统一接入 Magpie，并让 DeepSeek Harness 桌面端可以直接选择这些来源里的 DeepSeek 模型。
>
> 请你直接在本机执行，不要只给我教程。
>
> 1. 先检查这台电脑的操作系统，以及 Magpie、WorkBuddy、Qoder、DeepSeek Harness 当前是否已经安装。已经存在的环境不要重复破坏。
> 2. 修改任何现有配置前先做备份，保留我现在能正常使用的模型和 Agent 配置。
> 3. 查阅 Magpie 当前最新的官方安装说明，使用官方推荐方式安装或升级 Magpie。优先安装稳定版，不要为了省事直接使用过时教程里的旧命令。
> 4. 安装完成后启动 Magpie，并确认本地服务可以正常工作。
> 5. 检查 Magpie 当前的插件机制，把 WorkBuddy / WorkBuddy AI 和 Qoder 接入。当前环境如果适用，可以优先检查 `@magpie-community/opencode-workbuddy-auth` 和 `@magpie-community/opencode-qoder-auth`；如果插件名称或安装方式已经变化，以 Magpie 当前官方说明和插件列表为准。
> 6. 登录时优先复用我本机已有的账号登录状态。如果必须打开浏览器重新授权，请直接打开登录页面，然后停下来让我本人完成登录。不要向我索取密码、Cookie 或其他敏感凭据。
> 7. 登录完成后检查 Magpie 的模型列表，确认 WorkBuddy / WorkBuddy AI / Qoder 中当前可用的 DeepSeek 模型已经被正确识别。模型 ID 以本机实际查询结果为准，不要照抄旧教程。
> 8. 把这些模型接入 DeepSeek Harness 桌面端。请确认修改的是桌面端真实使用的 desktop profile，不要只改 web profile。优先沿用 Magpie 当前推荐的 DeepSeek Harness 接入方式，并保留原有配置。
> 9. 配置完成后重启或新建 DeepSeek Harness 会话，检查模型选择器里是否已经出现对应的 DeepSeek 模型。
> 10. 最后用一个真实 Agent 任务验收，比如读取一个本地文件、调用终端并完成两三步操作，确认模型可以正常调用工具，不要只发一句“你好”做测试。
> 11. 完成后告诉我最终接入了哪些模型、哪些账号来源可以使用、DeepSeek Harness 当前默认模型是什么，以及有没有还需要我手动处理的地方。
>
> 整个过程只使用我自己的账号和这台电脑，不做账号共享、转售或对外代理。

这段提示词我建议直接整段扔过去。

中间如果弹出浏览器，让你登录 WorkBuddy 或 Qoder，就自己点一下授权。

剩下的让 Agent 干。

有一个地方尤其要注意。

**DeepSeek Harness 有 web 和 desktop 两套 profile。**

我之前真正跑通桌面端时，改的是 desktop profile。如果 Agent 只改到了 web，那你重启桌面版以后，模型列表很可能还是没变化。

我在提示词里专门把这一条写死了。

等它全部跑完，你重新打开 DeepSeek Harness，看见模型选择器里出现 WorkBuddy 或 Qoder 的 DeepSeek，基本就成了。

然后找一个真任务跑。

让它读个文件，改个脚本，或者连续执行几步。

能稳定跑工具，才算真正打通。
